# COMP1238 - My Course Notes

## Week 1 - History
- Early writing was used to record information, such as goods and transactions.
- Cuneiform used wedge-shaped marks pressed into clay tablets.

## Week 2 - Bits and Bytes
- A bit is a binary digit that can have a value of 0 or 1.
- One byte contains 8 bits and can represent 256 different values.
## Week 3
- Whitespace includes spaces, tabs, and newlines.
- A newline character marks the end of a line in a text file.
## Week 4
- Touch typing means typing without looking at the keyboard.
- Keyboard shortcuts help us complete common tasks more quickly.
## Week 5
- A command-line interface lets us control a computer by typing text commands.
- Commands can include arguments and options that control what they do.
